# Name check: "WebWrap" and "WebWrap Studio"

Checked 2026-09-25 with web search, the npm registry search API and the GitHub search API. This is a quick collision scan, not a trademark clearance and not legal advice. Ask a trademark attorney before you spend money on a domain, logo print runs or a launch.

## Risk level: HIGH

- The exact name "WebWrap Studio" is in use by two web-services businesses in the same broad field (web and software). Two are named nearly the same, in different countries.
- "WebWrap" alone is a descriptive, crowded term (web + wrap) and is used by a tool doing the same job.
- Search ranking and the .com domain will be hard to win. Trademark registration is likely to meet objections.

## Recommendation

Do not launch as "WebWrap Studio". Rename before buying a domain (M6). Paneshell is the cleanest on this scan; Tilefold matches the logo idea best. Before committing, check the domain registrar, the app stores, and a trademark search for the chosen name. The logo files in this folder use the wordmark text "WebWrap Studio"; only the text line needs to change.
